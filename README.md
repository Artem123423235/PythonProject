## Цель проекта
Этот проект предназначен для обработки данных о транзакциях, позволяя фильтровать и сортировать их по состоянию и дате.

cd my_project


3. Убедитесь, что у вас установлены все необходимые зависимости. (Уточните их, если они есть.)

## Использование

### Функции

1. `filter_by_state(data, state='EXECUTED')`
- **data**: Список словарей с данными о транзакциях.
- **state**: (опционально) Значение для фильтрации по ключу 'state'. По умолчанию 'EXECUTED'.
- **Возвращает**: Новый список словарей с указанным состоянием.

**Пример использования**:
```python
data = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
]
executed_transactions = filter_by_state(data)

sort_by_date(data, descending=True)

data: Список словарей с данными о транзакциях.
descending: (опционально) Порядок сортировки. По умолчанию True (по убыванию).
Возвращает: Новый отсортированный список.
Пример использования:

sorted_transactions = sort_by_date(data)


# Financial Transactions Processor

## Описание

Этот проект предназначен для считывания и обработки финансовых транзакций из файлов в формате CSV и XLSX. Основная функциональность включает в себя загрузку данных из этих файлов и их представление в виде списка словарей.

## Структура проекта

PythonProject/ │ ├── main.py # Основной файл, запускающий программу ├── data_loader.py # Модуль для работы с данными (загрузка из CSV и Excel) ├── decorators.py # Модуль, содержащий декораторы для логирования ├── transactions.csv # Пример CSV файл с данными транзакций └── transactions_excel.xlsx # Пример XLSX файл с данными транзакций


## Установка

1. Клонируйте репозиторий с проектом на свой компьютер:
   ```bash
   git clone <URL_репозитория>
   cd PythonProject
Создайте и активируйте виртуальное окружение (рекомендуется):

python -m venv venv
# Для Windows
.\venv\Scripts\activate
# Для MacOS/Linux
source venv/bin/activate
Установите все необходимые зависимости из файла requirements.txt:

pip install -r requirements.txt
Использование
Убедитесь, что у вас есть файлы transactions.csv и transactions_excel.xlsx в корневой директории проекта. Эти файлы содержат примерные финансовые транзакции.

Запустите основной файл main.py:

python main.py
Программа считает данные из обоих файлов и выведет первые 5 транзакций для каждого из них.

Функции
load_csv_transactions(file_path: str) -> list: Считывает финансовые операции из CSV-файла и возвращает список словарей с транзакциями.

load_excel_transactions(file_path: str) -> list: Считывает финансовые операции из Excel-файла и возвращает список словарей с транзакциями.
